Train the real model runs on your computer

The preview above is a simulation. The model this app uses (models/model.pkl, RandomForest, 200 trees) is trained with the repo's scripts. Run them from the project folder, then restart the server.

  1. 1. Collect samples for each sign (include no_sign)py -3.11 scripts/collect_data.py
  2. 2. Train and print random vs temporal split scorespy -3.11 scripts/train_model.py
  3. 3. Restart the web app to load the new modelpy -3.11 -m uvicorn backend.main:app --reload --port 8000
